# vuepress-boilerplate — risks and open questions

| ID | Risk | State | Notes |
|---|---|---|---|
| VP-A | `baseline-v1` is not yet proven live | OPEN | Proven offline in Baseline CI: the offline bootstrap with the blueprint's own hooks, the stage lane's own steps in a staged job tree, the site served by `wrangler dev` and smoke-tested with the component's own command, every address read. A console bootstrap closes it |
| VP-B | VuePress 1 and webpack 4 on the runners' Node | ACCEPTED | OpenSSL 3 refuses webpack 4's md4; webpack 4.47.0 falls back to its own WebAssembly md4, so `vuepress build` needs no `--openssl-legacy-provider` (spike on Node 26; Baseline CI on Node 22). VuePress 1 and Vue 2 are past their maintenance windows: no Node major is promised. The e2e tier and the deploy's build catch a Node that breaks it |
| VP-C | The site's config is restored from the live example, not taken from the template's source | ACCEPTED | The source ships no `.vuepress/config.js`; built as is, the site would be titled "VuePress" with no navbar or sidebar, unlike the demo Vercel's template page shows. The restored parts are the demo's own (read from its compiled site data); its defaults and unused demo components are not restored |
| VP-D | The home page's hero image is remote | WATCH | `heroImage: https://v1.vuepress.vuejs.org/hero.png`, as upstream's frontmatter has it, served by VuePress v1's own documentation site (200 on 2026-11-12). If that site goes, the hero shows a broken image until a product replaces it |
| VP-E | pnpm 10 skips the install scripts of VuePress's dependencies | ACCEPTED | core-js, highlight.js and vuepress only print notices; the build is proven with all of them skipped |
| VP-F | stack-tectonic 0.19.0, not 0.20.0 | ACCEPTED | 0.20.0's lane-shared install links each job's `node_modules` out of its tree; the siblings pin 0.19.0 for it and the site would save nothing |
| VP-G | An extension-less page address is a 404 | ACCEPTED | `/guide/using-vue` answers 404 with VuePress's 404 page, as on Vercel; VuePress's router has no route for it either. Every link VuePress writes names the `.html` |
| VP-H | VuePress 1's build toolchain carries known advisories | ACCEPTED | `pnpm audit` on 2026-11-12: 104 (4 critical), in build-time packages of VuePress 1's webpack 4 toolchain and its dev server. None runs in the deployed site, which is the built HTML, CSS and JavaScript and a twenty-line Worker. A product that keeps VuePress 1 keeps them; VuePress 2 is the way out |
| VP-I | pnpm installs `@vue/compiler-sfc` 3 as vue-loader 15's optional peer | ACCEPTED | pnpm's auto-installed peer; Vue 2.7 compiles its own single-file components and the build never loads it |
| VP-J | 03-docs needs PyYAML the build box lacks | RESOLVED | The siblings' hook imported `yaml` to read the public origin from `intent.yaml`, and console builds stopped at 03-docs with the site live (2026-11-06; fixed in 16 baselines on 2026-11-11). This hook was born with the fix: it uses PyYAML when present and reads that one key by indentation otherwise, and `testing/render.test.sh` runs it under a python3 with no third-party packages |
